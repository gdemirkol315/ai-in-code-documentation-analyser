Logging Overview

This documentation provides a comprehensive overview of all logging statements in the AI Documentation Analyzer tool. The application uses SLF4J with Logback for logging, configured to output to both console and rotating log files.

Logging Configuration

The logging is configured via src/main/resources/logback.xml:

<configuration> <!-- Console and File appenders configured --> <root level="INFO"> <appender-ref ref="CONSOLE" /> <appender-ref ref="FILE" /> </root> <!-- Package-specific logging levels --> <logger name="com.docanalyzer" level="INFO" /> <logger name="org.apache.http" level="WARN" /> <logger name="com.github.javaparser" level="WARN" /> </configuration>

Log File Location: logs/docanalyzer.log (with daily rotation, 30-day retention)

Usage Notes

  • DEBUG logs: Enable by setting log level to DEBUG in logback.xml or via system property -Droot.level=DEBUG
  • Log placeholders: {} represents dynamic values that will be substituted at runtime
  • Log file rotation: Daily rotation with 30-day retention policy
  • Console output: All logs are also displayed in the console during execution
  • Third-party libraries: Apache HTTP Client and JavaParser logs are set to WARN level to reduce noise
